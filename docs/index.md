# 文档索引

本页是项目文档的统一入口。项目概览与当前交付状态见 [README](../README.md)；按当前任务选择下面的主文档，仅在涉及关联职责时补充阅读。

## 维护路由

规格合同放在 `spec/`，来源与测绘资料放在 `references/`，已执行的核对及验收记录放在 `verification/`。新增、重命名或拆分文档时同步更新本页与相关链接。具体规则在对应主文档维护，README 保留项目概览和本页入口，避免维护第二份完整路由表。
