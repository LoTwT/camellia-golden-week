### 1.1 已发现的证据冲突

S05 的 A 区标题写全 30，但本轮读到其分项为 5×3、5×2、5×2，相加 35，存在内部不一致。不能从该分项推出正式奖励分配，也不能把疑似笔误直接改成“已验证原数值”。本版采用 [内容合同](../spec/content.md) 的 130 总量、A / B 首访各 25 + 回访各 5，并清楚标为设计账本。

S06 能证明存在后期回访，却没有证明本版“回访各给 20 数据”的规则。将 D 四权限设为回访开关、让回访数据参与开库，是为了去剧情后保留完整探索循环作出的设计。

S03 描述鼠标可以远点、快速点击可增加连击；本版防火墙保留局部远点，但明确每拍最多 +1。因此不能拿原作快速点击成绩直接比较本版阈值。S05 关于跟随节拍跨红格的说明仅作为机制线索，本版具体判定窗另行定义。

### 1.2 原版防火墙视觉节拍补核（2026-09-11）

`S10`：[TheWayCafe Productions 的原版1.1活动实机录屏](https://www.youtube.com/watch?v=Ua1SdQqcePc&t=1272s)，视频 `Ua1SdQqcePc`，21:12起的防火墙教学。本轮在浏览器实际查看该段至约21:49；右上角原游戏提示为“Light around the screen will blink in time with the beat”。这证实画面周围灯光提供视觉拍点，并非只能听音乐。S03正文第9步的屏幕白光说明与其一致；两侧COMBO电视、中央5列4行及红色危险格也在画面可见。

仅确认该段教学文案及可见表现，没有逐帧测量原版 BPM、判定容差、闪光曲线、音频偏移或全部难度。原视频仅作参考定位，没有下载或打包其影音。当前本版周边白光由DOM/CSS重建，峰值对齐本版权威拍点；亮度、范围和减少闪烁时的文字替代属于本版实现选择。5×5地图、每拍最多+1、120BPM和±150ms继续按玩法合同执行。实际修改和验证统一见[画面周边节拍修复](../verification/firewall-visual-cue.md#原版核对后的画面周边节拍补修)。
