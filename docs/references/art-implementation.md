### 4.2 状态与后续区域的补制语义

M1 新增状态保持形状差异：已用富集是空环与勾，数据 / 物资领取后保留外形与勾；锁定传送使用断续环和锁，已完成终端使用屏幕外框与勾；关闭门是门板 / 横杠 / 锁孔，开启门保留门框和通行箭头。危险为三角警号，与粉红底色共同表达；安全辅助图形是斜条空框。观察、检查点、防火墙分别使用眼形放大镜、旗帜和节拍音符。迷宫隐藏阶段是否显示危险图标仍由权威状态和投影层决定，资产不泄露隐藏危险。

B 普通蓝目标为单菱形像素十字，紫目标为双菱形与速度短线，星为五角星；三者静音 / 灰度下仍有不同轮廓。C 滑行球是圆球与经线，逐格推车是方车双轮，固定基站有底座和同心靶环；盗取对象是实体八边芯片，接收槽是空心括角与虚线孔，字母 / 颜色由投影层提供。D 幽灵按原参考使用深色本体、粉红双圆眼与下沿静态杂讯，避免误用砖墙颜色表示幽灵；亮灯有实心灯泡与放射线，未亮为空心灯泡加斜杠。D 状态差异均不依赖闪烁动画。

对危险 / 安全、数据 / 物资领取前后、开关门、三类杀毒目标、球 / 车 / 基站、盗取对象 / 接收槽、亮灭灯和幽灵共 19 项，另生成 44×44 像素灰度查看图并实际检查。上述轮廓和状态符号仍能区分；这是单图资产检查，不能代替 V03 对游戏内字母辅助、完整底色、声音设置与动态效果的实测。

## 5. 字体与声音

中文采用完整 **Noto Sans SC Regular** 的 SC 源字形集，源提交 `165c01b46ea533872e002e0785ff17e44f6d97d8`；从原 OTF 封装为 WOFF2，未按当前 UI 文本裁切。输出 `camellia-ui.woff2` 为 6,093,424 字节，31,036 个 glyph、30,890 个 cmap 映射。数字 / 英文标题采用 **Barlow Condensed Bold**，源提交 `89f5431ff0db41bd2fe3f7ba21a723a01622428b`，`camellia-numerals.woff2` 为 39,384 字节，694 个 glyph、525 个 cmap 映射。二者都保留内部字体元数据；OFL 放在各自字体旁。原游戏字体未确认，因此字体匹配状态是替代，不是“已找到原字体”。

封装工具为 fonttools `4.65.0`、brotli `1.2.0`。复现方式：从字体清单所指固定提交下载源 OTF / TTF，使用 `fontTools.ttLib.TTFont` 读取、设 `flavor = "woff2"` 后保存；不调用 subset。不复制本机系统字体作为成品字体。CSS 可用独立 family 名 `Camellia UI`（400）与 `Camellia Numerals`（700），避免依赖用户机器的同名字体。

声音目录为 `/assets/audio/`：`move.wav`、`invalid.wav`、`pickup.wav`、`reveal.wav`、`amplify.wav`、`door.wav`、`success.wav`、`failure.wav`、`portal.wav`、`beat.wav`。均为 44,100 Hz、单声道、16-bit PCM，时长 45–520 ms；4 ms 起音与 12 ms 收尾。峰值采样不超过 8,312 / 32,767（约 −11.9 dBFS），没有削波，首尾采样为零。`beat.wav` 的时长按采样量化为约 45.011 ms。

音色是加法合成的计算机式短反馈，未录制或采样原游戏。未核对原录屏声音，因此不能声称与原版的音色 / 起音 / 响度已完成对照。播放节流、音量 / 静音、首次手势启用、拒绝播放后无声继续、暂停取消排程及恢复时钟锚点由音频适配器负责，声音文件本身不定义玩法时钟。

## 6. 生成、检查与后续交接

[`scripts/generate-assets.ts`](../../scripts/generate-assets.ts) 用 Node 原生功能确定性生成 SVG、WAV 及总清单。默认只生成代表画面的 7 个图标；`--m1` 选择完整 M1 的 21 项状态集；`--all-profiles` 选择已预制的 33 项图标，并在每个条目输出 `profiles`。`--png` 同步生成 PNG，作者工具依赖 Sharp `0.35.4` / librsvg `2.62.91`；可用 `CAMELLIA_ASSET_SHARP_MODULE` 指定该作者工具的模块入口。Sharp 只用于离线资源生成，游戏运行和只读构建不依赖它。

常规生成命令为 `node scripts/generate-assets.ts --png`，M1 状态集为 `node scripts/generate-assets.ts --m1 --png`。若作者环境未安装 Sharp，先在隔离工具目录安装固定版本，并将 `CAMELLIA_ASSET_SHARP_MODULE` 指向该安装的 `sharp/dist/index.mjs`。不加 `--png` 时只生成 SVG / WAV；须显式重新生成 PNG 后才接入修改后的光栅缓存。

当前包含后续预备资源的清单用 `node scripts/generate-assets.ts --all-profiles --png` 复现；`--m1` 不会把后续图标写进所生成的 M1 清单，也不自动删除先前制作的其他文件。发布时依赖清单中的 `profiles` 过滤当前包，而不是把作者工作目录当作已过滤的成品。

只读检查命令为 `node scripts/generate-assets.ts --check`：检查唯一 ID、本地路径、源 / 输出 SHA-256、SVG 尺寸和无外链、PNG RGBA 与尺寸、WAV 格式 / 首尾 / 峰值、WOFF2 标记与 OFL 文件。该入口不创建目录、不重写清单、不生成资源，也不加载 Sharp。生成器源文件（包括格式）发生变化后应先重新生成清单，随后再运行只读检查。

已执行资源检查：先检查首批 7 项，再在代表图核对后检查完整 M1 的 21 项与 B / C / D 的 12 项，总计 33 张 SVG / 33 张透明 PNG 均实际显示查看；SVG / PNG 有效尺寸及透明通道检查；10 个 WAV 头、时长、采样峰值与首尾采样检查；两个 WOFF2 解码、glyph / cmap 数量检查；45 条总清单记录与各 profile 字段校验。首次 ImageMagick SVG 输出漏掉描边，已弃用该 PNG 输出并用 Sharp / librsvg 全部重导出，最终显示的门线、圆环与内部符号均存在。资源脚本独立 strict / noUncheckedIndexedAccess / exactOptionalPropertyTypes 类型检查、Oxlint 与 Oxfmt 检查通过；这不是整个应用工程检查的替代结果。

M1 所需状态已补齐，B / C / D 图标已预制。后续待各阶段实机验证：静态状态是否在正确时机显示、投影层是否保持非颜色编码、资产是否按 profile 过滤、六类场景的剩余视觉差异与动态 / 声音反馈。资源存在不推定玩法、阶段或验收完成。
