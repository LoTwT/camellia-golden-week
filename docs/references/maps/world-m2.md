# M2 B 区地图重建与见证

[文档索引](../../index.md) · [内容合同](../../spec/content.md) · [固定一笔画](static-puzzles.md) · [杀毒脚本](realtime.md)

本文件记录 M2 首访 B 区的固定世界地图。全部世界坐标属于**本版重建**，不代表原活动逐格测绘；局部一笔画和杀毒使用各自已有固定定义。本次新增路线动作 `b.nexus.north` 只记北侧清除过程，数据仍由 `b.north.terminal` 的末端交互产生，不增加物资、主路径或仓库条件。

## 来源与边界

`map.b.reconstructed` 对应 [b.json](../../../src/content/areas/b.json)。来源入口的 S04（[游侠第二日流程](https://m.ali213.net/news/gl2408/1481739.html)）已归档机制结论支持同一空洞传送、按钮、增幅节点、杀毒及回环；S05（[Game8 区域攻略](https://game8.jp/zenless/634710)）已归档机制结论支持 B 一笔画。这里仅沿用已有核对，没有新增原图测量或把攻略编号换算成地图坐标。

杀毒代表画面定位采用 [美术实施记录](../art-implementation.md) 的 `AR-B-ANTIVIRUS`：S05「侵食データ集め」，[图 ID 10419120](https://img.game8.jp/10419120/602cc237bdd8cf72a9ee0dcaa63dc430.jpeg/original)。它支持局部棋盘、蓝色波形屏和时间 / 成绩布局的对照；不证明本版的排期、寿命、5×5 尺寸或世界通路。完整原始地板集合、按钮与终端间距、北南分支朝向和奖励坐标仍未取得可核对定位。

## 公开操作见证

固定命令见 [m2.json](../../../src/content/witnesses/m2.json)，断言与迁移续玩见 [world-m2.test.ts](../../../tests/world-m2.test.ts)。命令只使用正常 `Move / ClickTile / Interact / Amplify / StartChallenge / Tick / ExitRoom / Teleport` 等输入；不写玩家位置、目标、门、分数或奖励。导航制作时只在已合法地板上寻路，房间逐步重放固定可解见证；杀毒操作时间均在目标出现后至少 150ms，时间源以不超过 250ms 的 Tick 前进。

`witnesses` 保存从 M2 新档开始的主路径和全收集流程；`continuations` 的起点引用真实 M1 固定见证终态，经 `stablePayload → validatePayload(M2, migrationRegistry) → restorePayload` 正常迁移，再执行 B 区命令。迁移注册表由实际 M1 / M2 内容视图与明确的 additive 步骤构成，不从载荷版本猜测来源结构。M1 的旧终点历史、奖励集合、布局与成绩保留，新增 B 数据 / 奖励使用未完成状态。

现行 schema 2 见证包含对保留完成布局的实际进入 / 普通行走 / 退出，再以 F 开启独立练习。首次 schema 1 联调时的 2,457 / 424,600ms 和续玩 1,156 / 173,400ms 属于此前入口规则的记录，不替代此次完成态回访证据。一笔画完成布局只保留“全部必经格已访问”的集合；活动尝试仍保留有顺序的路径，恢复不能把两者混用。

`node --test tests/world-m2.test.ts` 实际 **15 / 15 通过**，覆盖新档与真实 M1 迁移续玩、旧载荷不变与重复迁移幂等、主轴门和捷径门、独立奖励门、北侧清除与末端数据分离、一笔画非法动作 / 撤销 / 中途载荷恢复 / 重置 / 放弃 / 练习、杀毒超时失败 / 安全恢复 / 重试，以及 30 次完整 A/B 物理往返。`npm run typecheck` 与该测试文件的 Oxlint 检查通过。

这些是权威规则与载荷层的命令证据；浏览器正常键鼠、真实刷新、存储故障和视听记录由阶段集成验收提供，不能由合成时间源替代。C / D、M4 回访和仓库均未因 M2 见证通过而视为已验收。
