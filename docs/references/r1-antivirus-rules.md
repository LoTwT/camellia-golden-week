## 2. 具名适配 R1-B-ACCUMULATION-01

以下为实现前冻结的有限规则。三档分别绑定同一决定 ID；相同字段是明确的本版统一选择，不是原证据外推。

| 参数                | 轻度                                     | 中度                 | 重度                |
| ------------------- | ---------------------------------------- | -------------------- | ------------------- |
| 定义 ID             | `b.antivirus.light`                      | `b.antivirus.medium` | `b.antivirus.heavy` |
| 中央盘面 / 初始格   | 5×4 / `(2,0)`                            | 5×4 / `(2,0)`        | 5×4 / `(2,0)`       |
| 首次出现 / 之后间隔 | 1000ms / 1100ms                          | 1000ms / 850ms       | 1000ms / 650ms      |
| 有效时间截止        | 32000ms                                  | 40000ms              | 48000ms             |
| 达标分数            | 24                                       | 40                   | 60                  |
| 最大活跃蓝紫数量    | 9                                        | 9                    | 9                   |
| 类型次序            | 每第 8 个为星；其余每第 4 个为紫，其余蓝 | 同左                 | 同左                |

选择理由：增长的出现频率构成三档数量压力，门槛约需回收各档总有效分数的四分之三，允许错过个别操作；新时长与门槛针对持续目标及提前成功重新选定，与旧 45 秒计分模型不同。重档每次出现相隔 650ms，成功见证每个目标可在出现后 250ms 反应；键盘跨多格亦可利用尚未满 9 的缓冲。理论反应空间只证明脚本可玩性，不能替代正常浏览器键鼠验收。

### 生命周期、生成与占格

- 蓝 / 紫直到输入清除或挑战结束持续存在，没有过期时间；分别计 1 / 2 分，均计入活跃侵蚀数量。
- 星也持续存在，星本体 0 分，不计入侵蚀数量。星占一格，清除时与当前所有蓝 / 紫组成一次原子事务，各实例只加一次分；不清除、不触发其他星。新星不能自动清场，脚下生成任何类型也不会自动清除。
- 固定排表在内容 JSON 中显式列出。候选位置按逐行蛇形顺序循环：偶数行左到右、奇数行右到左；每档同一排表可重试 / 重放。首次候选为 `(0,0)`。运行不调用随机数。
- 占格冲突按中央棋盘行优先顺序，从候选位置起循环选择第一个空格。实际位置保存于目标实例，渲染和点击使用该位置，不能用候选位置覆盖活跃对象。玩家不占目标槽。
- 极端边界全部 20 格已有目标时，下次生成立即以 `boardFull` 失败；不吞掉生成、不替换旧目标、不产生分数。正式排表正常不输入会先触发第 10 个蓝紫失败，满格仅为额外可验证边界。
- 同刻生成按稳定实例 ID 的 ASCII 顺序全部落位，再检查蓝紫数量。计划不能重复实例 ID；生成间隔和结束前最后目标的反应时间均至少 150ms。验证器拒绝不满足底线或无法构成数量压力的正式配置。

### 输入、同刻与结束

1. 时间轴以单调有效毫秒推进；暂停 / 失焦由公共时钟冻结。非有限时间、回退、未来输入、旧序号忽略；同刻输入按递增序号。纯规则输入可批处理，也可按帧分段，结果与事件序列一致。
2. 截止时刻最优先：有效区间 `[0,durationMs)`。到截止还没成功即失败，截止同刻不生成、不处理输入；剩余目标保留为失败画面证据。
3. 截止前同刻为「生成全部实例 → 检查数量 → 输入按序执行 → 每次清除事务后判达标」。蓝紫数量 9 合法，10 立即失败；同刻星星点击或普通清除不能救回已经超限的局面。第 10 次出现有排表间隔及已有堆积作为预警，不设计必须反应于出现瞬间的抢救输入。
4. 点击有效目标直达并清除；带已消失实例 ID 或不匹配实际位置的点击视为过期输入，不移动也不清掉随后生成的新实例。无实例 ID 的空格点击仅移动；有目标则清除。方向移动只走邻格并清除落点；撞边无效且不清脚下目标；F 清当前格。
5. 达标在清除事务全部完成后立即成功，即使一颗星一次超出门槛也完整计分，然后停止后续输入 / 生成。没有「先达标后在尾时超限」；不达标即使活到截止也失败。侧屏分数进度以 `min(score / targetScore,1)` 显示，数量以活跃蓝紫 / 9 显示，计时单独显示。
6. 结束状态与首次结束反馈幂等；失败后使用正常重试创建完全相同初态，放弃返回已有安全 B 终端。规则模块不写永久目标或奖励，由主引擎既有成功事务开放对应 5 单位物资格；练习不重复领奖。旧 v3 成绩不能参与 v4 最好成绩比较。

以上所有未知参数、初始格、排表、超限优先级、星星边界、提前成功及其 UI 派生均属于本版适配。5×4 / 四侧屏恢复不得因适配删除；原图的 9 上限证据范围仍仅限该图所示模式。原版时长、随机性与逐档规则一致性继续明确未验证。
