三份试听通过 FFmpeg 9.0.1 解码后各为 **29.952333 秒**。处理方法如下，可独立于临时目录复现：

1. 使用 `ffmpeg -v error -i <试听文件> -ac 1 -ar 12000 -af <频带过滤> -f f32le -`，读取小端 float32 单声道采样。
2. 分别使用 `lowpass=f=180`、`highpass=f=300,lowpass=f=2500`、`highpass=f=3000` 与 `anull` 得到低、中、高、全频四路。
3. 每 60 个采样计算一次 RMS，即 5ms 一个窗口。当前 RMS 减去此前最多 10 个窗口的均值，负值归零，得到起音包络；第一窗起音记为零。
4. 从包络减去全段均值，记结果为 `y`。对滞后 `L` 计算 `sum(y[i] * y[i-L], i=L..N-1) / sum(y[i]², i=0..N-1)`。
5. 比较约 110 / 120 / 135 / 140 BPM 的滞后及两拍周期。5ms 网格分别取 545 / 500 / 445 / 430ms，两拍取 1090ms；这些离散取值不声称具有毫秒以下测量精度。

| ------ | ------------------: | ---------------: | ------------------: | ------------------: | ---------------: |
| Red!   |             0.47284 |         −0.04048 |            −0.06388 |            −0.03026 |          0.70016 |
| Red!!  |             0.80634 |         −0.07867 |            −0.06828 |            −0.01375 |          0.77874 |

高频包络在 1090ms 的相关值分别为 0.90351 / 0.82572 / 0.90001；Red!! 低频包络在 545ms 达到 0.80979。低频单独分析 Red! / Red!!! 时，主要强峰位于两拍周期，因此没有把低频中的弱单拍峰隐藏为“三曲每个频带都有同样强峰”。

这些观测支持三份参考录音具有**约 110 BPM 的节奏周期**；55 / 220 BPM 的半速或倍速计拍存在等价性。第三方 [SongData 专辑页](https://songdata.io/album/74Y0dW8JxYd5lvohIVLv8x/-by-Sn-Z-HOYO-MiX)分别标为 140 / 135 / 110 BPM，前两项与本次样本的实际起音周期冲突，未用于本版速度选择。

**本次没有测出原游戏的精确谱面、判定拍选择、第一拍偏移、判定容差、音乐与输入的延迟补偿、各难度整曲播放范围或危险格脚本。** 这些仍需将原游戏视觉闪光、音乐与实际输入事件对齐测绘；音乐周期分析不替代正常游玩，也不证明成绩与原版完全相同。

## 4. 本项目的三首原创循环配乐

本次增加 [`scripts/firewall-music.ts`](../../scripts/firewall-music.ts)，独立合成三首电子节奏配乐。其声音由确定性振荡器、包络和固定种子的噪声生成，没有读取、录制、采样上述试听，没有复制原曲旋律。全部标为**原创补制**，不命名为 Red!、不声称是原曲的音色或编曲复原。

| 稳定 ID                | 声部与差异                                       |
| ---------------------- | ------------------------------------------------ |
| `firewall-music-inner` | 每拍底鼓、二四拍军鼓、八分踩镲、切分低音与短和弦 |
| `firewall-music-deep`  | 同一基础律动，增加切分低音、和弦频度和短分解     |
| `firewall-music-core`  | 进一步增加踩镲、分解密度及乐句末军鼓过门         |

音乐为 D 小调的原创八小节乐句，每首 **110 BPM、32 拍**，文件零秒对应第一拍；采样量化后长度为 769745 帧，即 17.454535 秒。暂停、倒数恢复、静音和音乐起点与判定拍的偏移由[音频适配器](../../src/audio/audio.ts)处理，音乐生成器不定义游戏有效时钟或通关规则。新的源码和本页不依赖 `/tmp` 中的试听或研究报告。
