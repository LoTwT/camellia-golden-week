## 来源与补制

杀毒依据 S05-39 原图已确认的中央 5×4 电视及四块蓝色侧屏。`src/render/antivirus-stage.ts` 复用现有防火墙侧屏外壳几何，仅以独立 CanvasTexture 绘制波形和本局清除进度；侧屏的具体波形、数值字号与填充为本版补制。没有修改防火墙的 stage 或 CSS。

盗取对照 `docs/verification/evidence/r1-source/theft-01-start.png` 及地图证据中逐帧定位，使用独立 DOM 平面终端、方格地板与两侧深色控制台。`src/render/theft-panel.ts` 内置 SVG 分别绘制球、固定基站、球站组合体、电源接口、玩家和完成出口，缓冲区以 CSS 斜纹表示；不是 TV 格壳或同色箱子。A/B/C 字母、颜色和类别形状并用，未知接口按权威 projection 隐藏，全部组装后的供电与完成状态也只消费 projection。

## 接线与可访问性

`BoardRenderer` 根据 `board.antivirus` 或 `board.theft` 选择专用呈现。杀毒脚下新生目标与玩家同时可见；四屏累计进度来自权威分数。盗取格只发送现有 `ClickTile` 回调，接入 main 已有对话框与转场保护；主要指针按下一次只产生一次正常命令，随后焦点回到游戏 canvas，避免 DOM button 与全局 Enter 重复触发。键盘方向、F、Z、重置、放弃沿既有命令通道。

杀毒结果显示本次清除、门槛、本规则最佳与最大星清。历史成绩严格按 challengeId 与该定义的 ruleVersion 匹配：防火墙仍为 3，杀毒为 4。C 始终同时显示字母与类别形状，颜色不作为唯一线索。少动态或少闪烁均使侧屏波形冻结，静音仍由现有音频设置控制。
