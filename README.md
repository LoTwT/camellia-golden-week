# camellia-golden-week

《绝区零》「沙罗黄金周」（Camellia Golden Week）空洞电视格子玩法的单人本地复刻。保留探索、机关、格子内挑战与四区联动，移除剧情、空洞外流程和动作战斗。

已按用户批准的 bfb924b 规格进入连续实施。当前可运行内容为 M1：中心区、A 区首访、三个记忆迷宫、防火墙教学及三个正式档位、26 单位物资和本地存档。实际检查与未验证项以[实施进度](docs/verification/implementation-progress.md)和[验收记录](docs/verification/acceptance-results.md)为准。

项目文档统一从 [文档索引](docs/index.md) 进入，按任务查阅主规格、玩法、内容数据、工程、验收与来源记录。

地图和判定为规格约定的固定重建；未经证实的逐格、像素与时序不宣称原版一致。实际资源、许可、校验值与补制差异见[美术实施记录](docs/references/art-implementation.md)。

运行要求为 Node 24.18.0 与 npm 11.16.0。安装后使用固定的本地来源 http://localhost:5174；端口占用时服务明确报错。

## 安装与运行

```sh
npm ci
npm run dev -- --host localhost --port 5174 --strictPort
```

打开 [localhost:5174](http://localhost:5174)。成品构建按以下命令运行；先关闭 dev，避免占用同一端口。

```sh
npm run build
npm run preview -- --host localhost --port 5174 --strictPort
```

dist 目录包含运行所需图片、字体、声音与内容；通过本地 HTTP 服务运行，不能直接双击 HTML。安装依赖需要 npm 注册表，游戏运行不访问外部服务。发布包只包含所选 profile 的内容与共享资源。

## 操作与进度

| 操作          | 键盘 / 鼠标                                    |
| ------------- | ---------------------------------------------- |
| 移动          | WASD / 方向键；点击相邻格                      |
| 交互 / 增幅   | F / R；底部同名按钮                            |
| 区域图 / 暂停 | M / Esc                                        |
| 静态机关      | Z 撤销；底部重置或返回入口                     |
| 防火墙        | 跟随拍点按方向或点击不同格，每拍最多计一次     |
| 菜单          | Tab 切换焦点，Enter / Space 确认；Esc 返回探索 |

点击远处只会沿已访问的安全格逐步行走。隐藏路线、机关与未领取物资不能靠自动寻路跳过。实时挑战在菜单、失焦或时钟中断时冻结，需主动恢复，恢复倒数不计入挑战时间。

稳定行动自动保存到双槽，启动时选择继续。一个浏览器来源同时只有一个可写窗口；另一个窗口可以导出或等待原窗口关闭。存档属于当前浏览器的 http://localhost:5174；更换浏览器、主机或端口请使用“菜单 → 进度与存档 → 导出 / 导入”。导出文本也可保存为 .json 文件；导入会校验并预览，确认且写入成功后才替换。发生存储失败时保留内存进度并显示未保存，可导出或重试；较新版本、坏档和迁移失败不会静默覆盖原档。

本版主路径与收集分开：A 主终端可在完整数据 20/100 时完成；M1 首访数据收齐是 80/80，完整版仍为 80/100。计分挑战不阻挡主路径。后续包升级保留已完成和已领取 ID，增加内容分母。
