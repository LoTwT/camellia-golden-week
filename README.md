# camellia-golden-week

《绝区零》「沙罗黄金周」（Camellia Golden Week）空洞电视格子玩法的单人本地复刻。保留探索、机关、格子内挑战与四区联动，移除剧情、空洞外流程和动作战斗。

**当前交付：中文规格 v0.1，待审阅。** 技术栈已确定为 Vite + TypeScript + Three.js；仓库尚无应用、依赖或可运行命令。

项目文档统一从 [文档索引](docs/index.md) 进入，按任务查阅主规格、玩法、内容数据、工程、验收与来源记录。

文档中的具体规则和数值是本次提出的复刻版设计，除明确列出的用户约束外，不表示用户已逐项批准，也不表示已实现或已通过游戏验收。原地图逐格坐标、视频时序与原版判定参数尚未测绘；各区域制作时须交付固定地图、来源定位、改造记录和通关记录。

下一步是按规格启动 M1（中心区 + A 区首访内容）。当前仓库仅包含文档与 Agent 配置，尚未初始化工程或安装依赖。
